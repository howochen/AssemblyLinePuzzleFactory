# MVP v0.5 修改與驗證

日期：2026-10-09。Cocos Creator 3.8.8。

## 修改

- 使用 Cocos `sys.localStorage` 保存每關最佳星級與上次選關；較低星重玩不降低最佳評價。
- 七個選關按鈕直接顯示完整星級，通關後即時更新。
- 加入出貨清單，標示當前、待出貨、已送達的訂單。訂單以原始貨箱顏色區分，加工後顏色以棋盤貨箱為準。
- 重開回到上次選關，當前嘗試從初始配置開始，不保存途中動畫或未完成訂單。
- 存檔資料驗證與異常處理：格式錯誤／無效值回退，儲存不可用仍可執行，通關訊息說明評價僅保留於當次。
- 未修改入口場景或刪除既有資源。

## 編譯及自動檢查

- 58 項模型測試與 13 項存檔測試，合計 71 項通過。
- 存檔測試涵蓋保存／恢復、最高星級、選關、非法索引／星級、損壞 JSON、版本不符、新增關卡與讀寫拋出例外。
- TypeScript 型別檢查通過。
- Web Mobile 完整建置成功，Creator 退出碼 36；輸出包檔案、3.8.8 引擎、Factory 入口與直向 720×1280 檢查通過。

## 實際預覽

- 預覽網址 `http://127.0.0.1:8089/`，使用生成的完整遊戲包。
- 七關星級、出貨清單正常顯示；選擇第七關後重新載入，正確恢復第七關與初始嘗試。
- 第七關第一箱送達後清單更新為紅箱已完成、藍箱當前出貨，棋盤與出貨計數一致。
- 4 次旋轉完成兩箱，顯示三星與「評價已保存」，頂部當關立即顯示完整三星。
- 再次重新載入後保留第七關與三星，當前嘗試、加工進度、貨箱與旋轉數正確回到初始值。
- 用 8 次旋轉重玩得到一星，當次通關顯示一星，頂部最佳紀錄仍為三星；瀏覽器捕獲 warning/error 日誌為空。
- 一星重玩後再重載，仍恢復三星最佳紀錄及第七關，未完成嘗試重置為 0 次旋轉、0/2 加工。

## 限制

- 本機 Web 存檔限定同一瀏覽器及同一來源；其他網址／埠、原生包或不同裝置不共用。
- 尚未測試手機實機、原生安裝包、安全區與長時間效能。
- 儲存不可用及損壞資料以測試替身驗證，未改動使用者瀏覽器儲存權限。
- 本次透過 Creator CLI 建置，未另行操作編輯器 GUI。
- 本次實際畫面為桌面 1280×720 視窗中的直向遊戲，未完成新版手機尺寸驗證。
