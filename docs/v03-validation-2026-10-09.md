# MVP v0.3 修改與驗證

日期：2026-10-09。Cocos Creator 3.8.8 / TypeScript。

## 修改

- 增加頂部 1～6 關選擇；切關重置當前嘗試並停止貨箱動畫。
- 第 4～6 關整關旋轉預算為 8、7、7 次，出貨間保留計數，固定輸送帶不消耗次數。
- 預算耗盡會拒絕旋轉並提示，可繼續出貨或重置。前三關維持無限制教學。
- 顯示旋轉計數、預算與三星目標。三星門檻為 4、9、16、4、3、3 次；門檻加兩次內為二星，其餘為一星。
- 最佳評價保留在當次執行的記憶體，已通關關卡顯示星號；重新整理不保存。
- 未覆蓋入口場景或刪除資源。

## 已驗證

- TypeScript 檢查通過。
- 44 項邏輯檢查通過，涵蓋六關既有規則、預算邊界、重置、選關、一／二／三星與共用加工路線。
- Creator 完整 Web Mobile 建置成功，退出碼 36，輸出包啟動檔、引擎版本、入口場景及直向解析度檢查通過。
- 實際輸出包 `http://127.0.0.1:8089/` 已確認新版載入、直接選關、第四關預算 8 次耗盡後拒絕第九次旋轉，仍可按開始出貨。
- 出貨後透過選關切到第五關，貨箱、狀態與預算正確還原。
- 第五關保留同一加工路線給兩箱使用，實際 3 次旋轉通關並顯示三星。切到第六關後第五關完成標記仍存在。
- 第六關兩箱依指定加工路線完成，實際 3 次旋轉通關；出貨間預算保持累計。瀏覽器捕獲 warning/error 日誌為空。
