# MVP v0.2 玩法與驗證報告

日期：2026-10-09。引擎：Cocos Creator 3.8.8。

## 修改

- 保留原三關與入口場景，新增雙色分流、染色加工、加工與分流，共六關。
- 紅／藍貨箱依序出貨，全部送達才算過關。每箱送達後暫停，保留方向配置，允許調整下一箱路線。
- 加入固定輸送帶、同色出口、染色站與指定加工要求。貨箱抵達加工站後會變色。
- 重置會還原整關、送達數、顏色、加工狀態與迴圈紀錄。
- UI 顯示加工站、固定輸送帶及出貨進度；不修改重要場景、不刪除資源。
- 修復建置腳本取得空退出碼，以及重導管線被 Electron 子程序持有而阻塞的問題。改用 .NET Process 等待 CLI；診斷使用官方 logDest 日誌。

- TypeScript 型別檢查通過。
- 35 項模型檢查通過：原三關、分流、錯色、染色、指定加工、固定輸送帶、雙箱、迴圈、重置與切關。
- Web Mobile 完整建置成功，Creator 退出碼 36，輸出包檢查通過：3.8.8、Factory 入口、直向 720×1280、啟動檔與 bundles。
- 在 `http://127.0.0.1:8089/` 的實際輸出包，以滑鼠點擊畫面通過全部六關，逐關切換，最後由第六關回到第一關。

- 第五關：紅箱經藍色加工站後成功送達，下一個藍箱走中央捷徑通關。
