# 流水線解謎工廠 · MVP v0.5

Cocos Creator 3.8.8 / TypeScript / 720 × 1280 直向。

## 執行

1. 用 Cocos Creator 3.8.8 開啟此專案。
2. 在資源面板雙擊 `assets/scenes/Factory.scene`。
3. 按上方預覽按鈕。若從外部修改腳本，先讓編輯器完成資源匯入與編譯，再重新預覽。
4. 點擊可旋轉輸送帶，使箭頭順時針旋轉 90°，按「開始運送」。貨箱須完成加工要求並到達對應顏色出口。
5. 共有七關，可按頂部按鈕選關。全部貨箱成功送達後可按「下一關」，最後一關完成後回到第一關。
6. 「重新配置」重置本關嘗試；「撤銷旋轉」只還原本次出貨前的配置操作。最佳評價與上次選關保存在本機。

UI 與貨箱以 Cocos Graphics 原生繪製，無外部美術依賴。畫面採深色工廠、薄荷綠箭頭、彩色貨箱與堆疊陰影。
場景內 Canvas 掛載 FactoryGame，UI 在執行時建立；編輯器場景視窗未進入預覽時只顯示 Canvas。

## 檔案

- `assets/scripts/PuzzleModel.ts`：關卡與純邏輯，四個方向、運送、失敗、循環防護、完成及切關。
- `assets/scripts/FactoryGame.ts`：原生 UI、觸控、動畫與直向解析度。
- `assets/scripts/ProgressStore.ts`：本機星級與選關存檔、資料驗證與儲存失敗處理。
- `assets/scenes/Factory.scene`：依官方 3.8.8 2D 場景範本建立的入口。
- `tests/model-test.cjs`：58 項邏輯檢查，涵蓋七關、加工順序、撤銷、旋轉預算、評價與選關。
- `tests/progress-test.cjs`：13 項存檔檢查，含重載、最佳星級、異常資料與儲存不可用。
- `MVP-v0.1-validation.md`：實際驗證範圍及限制。

## 檢查指令

在專案目錄執行 `npm test` 與 `npm run typecheck`。目前指令使用本機官方 Creator 3.8.8 安裝內附 TypeScript，換電腦須調整該路徑。
型別檢查跳過引擎 `.d.ts` 內部檢查，仍檢查遊戲 TypeScript；引擎宣告含 WebGPU 等外部型別，直接檢查全部宣告會產生與遊戲無關的錯誤。

## Web Mobile 完整建置與本機預覽

在 PowerShell 的專案目錄執行 `./tools/build-web-mobile.ps1`。
預設使用此電腦已安裝的 Cocos Creator 3.8.8；可用 `-CreatorPath` 指定其他安裝路徑。
建置設定在 `tools/web-mobile-build.json`，明確指定 Factory 入口場景、debug 布林值與直向模式。
建置器使用官方 3.8 的 `--project` / `--build configPath=...` 參數。首次引擎編譯可能耗時數分鐘。

成功條件為 Creator 退出碼 36 且存在 `build/web-mobile/index.html`。本次建置日誌保存在 `build/web-mobile-build.log`，退出碼存於 `build/creator-build-exit-code.txt`。CLI 輸出會顯示於終端。
接著執行 `npm run test:build`，檢查輸出包啟動檔案、Factory 入口、3.8.8 引擎與直向 720×1280 設定。

建置成功後執行 `npm run preview:build`，開啟 `http://127.0.0.1:8088`。
此伺服器僅供本機驗證生成的完整包，綁定 loopback，不是對外發布。按 Ctrl+C 停止。
換用其他埠可在 PowerShell 設 `$env:FACTORY_PREVIEW_PORT = '8089'` 後啟動。

Web Mobile debug 建置版已於 2026-10-09 實際測試三關通關、切關與失敗重置；詳見 [建置驗證報告](docs/web-mobile-validation-2026-10-09.md)。遊戲啟動時會隱藏 profiler 統計面板，避免遮擋手機按鈕。

尚未交付 Android / iOS 安裝包，手機實機觸控、安全區與效能需另行測試。

## v0.2 玩法

保留前三關教學，新增第 4～6 關：雙色分流、染色加工、加工與分流。
紅、藍貨箱必須送到同色出口；染色站會改變貨箱顏色，灰色箭頭為固定輸送帶。
貨箱依序出貨，每箱送達後暫停，可重新旋轉共用路線，再按「開始運送」。全數送達才可切關。
第六關另要求完成指定染色，直接送到同色出口也不算完成。重新配置會重置整關。

v0.2 已完成六關實際輸出包通關測試，詳見 [v0.2 修改與驗證報告](docs/v02-validation-2026-10-09.md)。

## v0.3 挑戰與選關

上方 1～6 按鈕可直接選關；切關會重置當前嘗試，也可中止運送動畫。
前三關不限制旋轉，第 4～6 關整關預算分別為 8、7、7 次；固定輸送帶不消耗次數。
旋轉預算用完仍可開始運送，或重新配置整關。每箱送達不會補充次數。
三星目標依序為 4、9、16、4、3、3 次；通關超過目標兩次以內為二星，其餘為一星。
當次遊戲的最佳評價保留在記憶體，重新整理不保存。

修改與實際測試範圍見 [v0.3 驗證報告](docs/v03-validation-2026-10-09.md)。

## v0.4 加工順序與撤銷

新增第七關「雙段加工配方」：每箱都必須先經藍站，再經紅站，才能送至紅出口。
跳過加工或順序錯誤皆失敗，畫面顯示當前箱的加工進度。旋轉預算 8 次，三星目標 4 次。
七個頂部按鈕可直接選關。底部「撤銷旋轉」還原最後一次配置並退回一次額度；只允許撤銷本次出貨前的操作。
按下開始出貨即清除撤銷紀錄，交接下一箱不退回先前箱的旋轉次數；整關重置或選關也會清除撤銷紀錄。

詳細測試範圍見 [v0.4 驗證報告](docs/v04-validation-2026-10-09.md)。

## v0.5 本機進度與出貨清單

使用 Cocos 的 `sys.localStorage` 保存每關最佳星級與上次選擇的關卡。頂部按鈕直接顯示一至三星。
重開會還原選關與評價，當前嘗試從初始配置開始，不恢復運送中的箱子或旋轉操作。
存檔僅保存在當前瀏覽器與同一網址來源；換埠、換瀏覽器、清除網站資料或使用原生包不會共用 Web 存檔。
新增出貨清單：▶ 為當前訂單、○ 為待出貨、✓ 為已送達。清單以每箱初始顏色標識訂單；箱子在加工後的顏色以棋盤上的貨箱為準。
異常存檔會回退可用資料或預設值，儲存被禁止時則在當次遊戲保留評價，通關提示會說明未能保存。

詳細測試範圍見 [v0.5 驗證報告](docs/v05-validation-2026-10-09.md)。
